## Data

All data in this portfolio is synthetic and generated by the scripts in the repository. Names are invented, email addresses use the reserved `example.com` domain, and national ID numbers carry a `999` prefix that the database itself requires, so no real BVN or NIN can be stored. No external dataset was used.
